# RAMP Navigation Hub — simple test page

This is a one-page test website.

## Files

- `index.html` — the complete webpage.

## Upload to GitHub

1. Open the empty `website` repository.
2. Click **uploading an existing file**.
3. Drag `index.html` onto the upload area.
4. Enter the commit message: `Add simple test landing page`
5. Click **Commit changes**.
6. Open **Settings** in the repository.
7. Select **Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select the `main` branch and the `/ (root)` folder.
10. Click **Save**.

GitHub will then display the web address for the published page.
